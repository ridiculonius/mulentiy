# Mulentiy Bot

Телеграм-бот на Aiogram 3 для подсчёта дневного заработка и ведения истории доходов.

## Требования
- Python 3.10+
- Aiogram 3.7+

## Установка и запуск

1. Склонируйте репозиторий и перейдите в каталог проекта.
2. (Опционально) создайте виртуальное окружение:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows: .venv\Scripts\activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Создайте файл `.env` и укажите токен бота от BotFather:
   ```bash
   cp .env.example .env
   nano .env  # впишите значение BOT_TOKEN
   ```
   Пример содержимого:
   ```ini
   BOT_TOKEN=1234567890:ABCDEFGHIJKLMNOPQRSTUVWXYZ
   ```
5. Запустите бота:
   ```bash
   python bot.py
   ```

При первом запуске будет создан файл базы данных `bot.db`, а журнал заполняется
примерными записями из репозитория автоматически.

## Основные команды
- `/start` – начать расчёт и открыть меню (кнопки: 🚀 Начать расчёт, 📜 История, 🔄 Повторить расчёт, 💾 Использовать прошлые значения)
- `/history` – управлять историей записей
- `/help` – краткая справка
- `/cancel` – отменить текущий шаг

При вводе сумм бот показывает последнюю сохранённую величину и кнопку **«Использовать прошлое»**. После каждого расчёта автоматически предлагается записать результат в журнал: бот вычисляет приход (разницу с предыдущим балансом), спрашивает причину траты и настроение (**Да / Не совсем / Нет**).
