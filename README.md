# Mulentiy Bot

Телеграм-бот на aiogram 3 для подсчёта дневного заработка и ведения простой истории.

## Запуск

1. Создайте файл `.env` на основе `.env.example` и укажите `BOT_TOKEN`.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите бота:
   ```bash
   python bot.py
   ```
